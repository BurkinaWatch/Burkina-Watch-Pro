9. VALIDATION DU SfM
====================

Une reconstruction ne peut être déclarée réussie que si COLMAP produit réellement un modèle sparse valide.

Vérifier au minimum :

* nombre d'images input ;
* nombre d'images enregistrées ;
* nombre de caméras ;
* nombre de points 3D ;
* observations ;
* éventuelle erreur de reprojection si disponible ;
* temps total ;
* mémoire approximative utilisée ;
* statut final de COLMAP.

NE PAS inventer de métriques.

Si 0 caméra ou 0 point 3D :

ce n'est PAS une réussite.

Si seulement quelques images sont enregistrées :

documenter le taux réel et déterminer si cela est acceptable.
