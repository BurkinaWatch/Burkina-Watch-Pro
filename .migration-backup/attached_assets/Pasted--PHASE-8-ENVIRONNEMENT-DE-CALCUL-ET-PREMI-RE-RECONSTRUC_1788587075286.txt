# PHASE 8 — ENVIRONNEMENT DE CALCUL ET PREMIÈRE RECONSTRUCTION

## CONTEXTE

Les phases précédentes ont établi l'architecture expérimentale Street View.

Architecture retenue :

VIDÉO
↓
EXTRACTION FRAMES
↓
COLMAP / SfM
↓
MVS
↓
3D Gaussian Splatting
↓
SCÈNE 3D

Le préflight précédent a montré :

* ffmpeg disponible ;
* ffprobe disponible ;
* espace disque disponible ;
* COLMAP absent ;
* GPU NVIDIA absent ;
* aucune reconstruction réelle encore effectuée.

Nous devons maintenant préparer un environnement permettant réellement d'exécuter le pipeline.

---

# OBJECTIF

Mettre en place un environnement de calcul expérimental permettant :

1. d'exécuter COLMAP ;
2. d'exécuter SfM ;
3. d'exécuter MVS ;
4. de préparer les données nécessaires à 3D Gaussian Splatting ;
5. de mesurer les ressources nécessaires ;
6. de déterminer si un GPU externe est réellement nécessaire ;
7. de conserver tous les résultats dans un environnement expérimental isolé.

Cette phase ne doit toujours PAS transformer le système en fonctionnalité de production.

---

# 5. INSTALLATION DE COLMAP

Installer COLMAP uniquement dans l'environnement expérimental choisi.

NE PAS l'installer dans le runtime principal BurkinaWatch si cela n'est pas nécessaire.

Documenter :

* version ;
* méthode d'installation ;
* dépendances ;
* support GPU ;
* mode CPU/GPU ;
* commandes utilisées.

Effectuer uniquement un test de fonctionnement :

COLMAP --help

ou une vérification équivalente.

Ne pas lancer encore une reconstruction coûteuse tant que l'environnement n'est pas validé.

---

# 6. TEST MINIMAL COLMAP

Avant d'utiliser notre vidéo, effectuer un test minimal permettant de confirmer que :

* COLMAP démarre ;
* les dépendances fonctionnent ;
* la base de données COLMAP peut être créée ;
* l'extraction/matching peut être exécuté ;
* les composants nécessaires sont opérationnels.

Le test doit être suffisamment léger pour éviter une consommation inutile de ressources.

Documenter le résultat.

* licence ;
* dépendances ;
* CUDA ;

* poses caméra ;

* extrinsics ;
* structure des fichiers ;

documenter précisément la conversion.

Ne pas encore construire un système automatisé complexe.
