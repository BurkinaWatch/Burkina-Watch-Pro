Cette phase a un objectif UNIQUE :

# 0. DÉCISION ARCHITECTURALE DÉFINITIVE

La décision suivante est NON NÉGOCIABLE :

```text
Railway PostgreSQL = seule base de données de production
```

Architecture :

```text
BURKINAWATCH
      │
      ├── Backend Node.js / Express
      │
      ├── Drizzle ORM
      │
      └── Railway PostgreSQL
             │
             └── SOURCE DE VÉRITÉ PRODUCTION
```

En production :

```text
Backend  → Railway PostgreSQL
Drizzle  → Railway PostgreSQL
```

`DATABASE_URL` peut continuer à servir au développement local.

Aucune autre base ne doit devenir une source de vérité concurrente.

La migration 0004 ne peut être appliquée à Railway que si toutes les conditions suivantes sont satisfaites :

```text
[ ] 29 tables confirmées
[ ] données intactes
[ ] migration 0004 auditée
[ ] aucun DROP/TRUNCATE/DELETE
[ ] indexes vérifiés
```
