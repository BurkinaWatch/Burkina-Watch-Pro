Ne rien recréer inutilement.

---

# ÉTAPE 2 — CHOISIR LE TYPE DE GPU

Pour le premier laboratoire, viser prioritairement :

**GPU NVIDIA avec environ 24 Go de VRAM.**

Pourquoi :

* marge suffisante pour les premiers essais ;
* meilleure sécurité contre les erreurs OOM ;
* permet de tester des datasets raisonnables ;
* évite de partir immédiatement sur un GPU très coûteux.

Un GPU de 16 Go peut être conservé comme solution économique secondaire si les tests montrent qu'il suffit.

Ne pas louer un GPU très haut de gamme sans justification.

---

# ÉTAPE 3 — COMPARER LES FOURNISSEURS

Avant tout lancement payant, comparer plusieurs fournisseurs GPU cloud actuellement disponibles.

Pour chacun documenter :

* GPU proposé ;
* VRAM ;
* CPU ;
* RAM ;
* stockage ;
* prix horaire ;
* facturation minimale éventuelle ;
* disponibilité ;
* accès SSH/terminal ;
* Docker ;
* persistance ;
* possibilité de destruction immédiate ;
* compatibilité CUDA ;
* possibilité d'installation COLMAP ;
* compatibilité PyTorch ;
* compatibilité 3DGS.

Ne pas inventer les prix.

Si l'environnement actuel ne permet pas de vérifier les prix en direct, indiquer clairement que le prix doit être vérifié avant provisionnement.

---

# ÉTAPE 5 — PROVISIONNEMENT

Si les credentials nécessaires sont déjà disponibles dans l'environnement de travail et que le provisionnement peut être effectué sans risque :

provisionner UNE SEULE instance temporaire.

Sinon :

NE PAS inventer de credentials.

* mot de passe ;
* clé privée ;
* token secret ;

Dans ce cas, fournir simplement la procédure exacte que l'utilisateur devra effectuer côté fournisseur.
