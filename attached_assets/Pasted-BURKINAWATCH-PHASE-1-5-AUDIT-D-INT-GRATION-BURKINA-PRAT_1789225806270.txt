==================================================
CONTEXTE PRODUIT
==================================================

BURKINA PRATIQUE existe déjà dans BurkinaWatch.

La version actuelle doit impérativement être conservée.

Elle possède notamment :
- catégories de lieux ;
- navigation vers les pages métier ;
- recherche ;
- recherche par intention ;
- explorateur ;
- carte ;
- liste ;
- cache/offline ;
- API des lieux.

Cette fonctionnalité existante constitue le SOCLE.

Nous voulons maintenant l'enrichir pour obtenir :

LIEUX + OFFRES + SIGNAUX + CONTEXTE DE SÉCURITÉ

L'objectif n'est absolument PAS de remplacer Burkina Pratique.

L'objectif est de la faire évoluer de :

"page d'orientation vers des catégories"

vers :

"outil pratique capable de comprendre un besoin concret, rechercher des solutions disponibles, intégrer des informations dynamiques et fournir un contexte de sécurité avant et pendant le déplacement."

PRINCIPE ABSOLU
==================================================

EXTEND > REPLACE

REUSE > DUPLICATE

ADD > REFACTOR

La fonctionnalité actuelle doit continuer à fonctionner.

Aucune catégorie existante ne doit disparaître.

Aucune donnée existante ne doit être supprimée.

Aucune fonctionnalité existante de BurkinaWatch ne doit être remplacée par une nouvelle implémentation simplement parce qu'elle pourrait être reconstruite différemment.
