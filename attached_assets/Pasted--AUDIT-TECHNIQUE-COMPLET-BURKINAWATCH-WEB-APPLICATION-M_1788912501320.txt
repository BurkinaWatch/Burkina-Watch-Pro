# AUDIT TECHNIQUE COMPLET — BURKINAWATCH WEB + APPLICATION MOBILE EXPO + OTA

## CONTEXTE

BurkinaWatch possède actuellement une application Web fonctionnelle qui constitue le produit principal et la référence du projet.

Je souhaite faire évoluer l'architecture afin d'obtenir, à terme, une expérience équivalente à celle que nous avons mise en place sur d'autres projets :

* le site Web reste la version principale et ne doit pas être cassé ;
* une application mobile native iOS/Android utilisant Expo doit utiliser le même backend et les mêmes fonctionnalités métier ;
* les évolutions compatibles doivent pouvoir être distribuées à l'application mobile via Expo OTA / EAS Update ;
* les fonctionnalités doivent rester synchronisées entre Web et Mobile ;
* Railway doit continuer à héberger le backend et les services nécessaires ;
* le projet doit rester maintenable par une équipe de développeurs expérimentés.

L'objectif n'est PAS de transformer artificiellement le site Web en application React Native.

L'objectif est de déterminer comment construire une architecture propre :

WEB + MOBILE EXPO + BACKEND/API PARTAGÉ + BASE DE DONNÉES PARTAGÉE + OTA.
