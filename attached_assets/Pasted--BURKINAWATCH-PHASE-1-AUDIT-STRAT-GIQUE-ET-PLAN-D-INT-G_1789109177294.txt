## IMPORTANT

Cette mission est STRICTEMENT EN LECTURE SEULE.

NE MODIFIE AUCUN FICHIER.

BURKINAWATCH est une application existante comportant déjà des fonctionnalités opérationnelles.

Nous voulons enrichir sa fonctionnalité actuelle de lieux/catégories avec une nouvelle couche appelée :

# BURKINA PRATIQUE

L'objectif n'est PAS de remplacer l'existant.

L'objectif est :

EXISTANT + NOUVELLE COUCHE INTELLIGENTE

---

# 1. RÈGLE ABSOLUE

Le principe de cette évolution est :

EXTEND > REPLACE

REUSE > DUPLICATE

ADD > REFACTOR

La fonctionnalité actuelle doit être conservée.

Cela inclut notamment, lorsqu'elles existent :

* catégories ;
* listes de lieux ;
* fiches ;
* carte ;
* recherche ;
* filtres ;
* géolocalisation ;
* itinéraire ;
* téléphone ;
* WhatsApp ;
* partage ;
* données existantes.

Aucune fonctionnalité existante ne doit être supprimée.

Aucune catégorie existante ne doit disparaître.

Aucun lieu existant ne doit être supprimé.

Aucune donnée existante ne doit être remplacée par des données fictives.
