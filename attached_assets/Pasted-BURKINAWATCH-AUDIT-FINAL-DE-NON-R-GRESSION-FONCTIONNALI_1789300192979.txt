5. PERFORMANCE
==================================================

Vérifie que la fonctionnalité n'effectue pas :

- polling excessif ;
- requêtes GPS permanentes inutiles ;
- requêtes API répétitives ;
- notifications répétées ;
- création massive de données ;
- consommation excessive de batterie ;
- consommation excessive de données mobiles.

==================================================
6. CONFIDENTIALITÉ
==================================================

- absence d'historique GPS inutile ;
- absence d'exposition publique de l'identité ;
- absence d'exposition du trajet ;
- séparation perception / incident ;
- absence de garantie de sécurité.
