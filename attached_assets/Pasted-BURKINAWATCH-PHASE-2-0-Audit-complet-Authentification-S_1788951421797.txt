1. OBJECTIF DE LA PHASE

L'objectif est de déterminer précisément si le système d'authentification actuel de BurkinaWatch est :

fonctionnel pour le Web ;
sécurisé ;
compatible avec la production Railway ;
suffisamment propre pour être étendu à une application mobile native ;
capable de permettre à Web et Mobile d'utiliser le même backend sans créer un deuxième système d'authentification.

Architecture cible :

                         BURKINAWATCH
                              │
                 ┌────────────┴────────────┐
                 │                         │
              WEB EXISTANT             MOBILE NATIF
                 │                         │
           React + Vite              Expo + React Native
                 │                         │
                 └────────────┬────────────┘
                              │
                         API COMMUNE
                              │
                       AUTH COMMUNE
                              │
                         EXPRESS
                              │
                         POSTGRESQL

Nous ne voulons :

ni deuxième backend ;
ni deuxième base ;
ni deuxième logique utilisateur ;
ni deux systèmes d'identité indépendants.
