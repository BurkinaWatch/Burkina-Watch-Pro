# PHASE 6 — ÉTUDE TECHNIQUE ET SÉLECTION DU MOTEUR DE RECONSTRUCTION 3D

## CONTEXTE

Le module Street View de BurkinaWatch est en cours de reconstruction.

L'objectif n'est PAS de créer un simple lecteur vidéo ou une fausse expérience 3D.

L'objectif à long terme est de permettre aux utilisateurs de contribuer à la reconstruction numérique du Burkina Faso :

* une personne filme une rue ;
* une autre filme un bâtiment ;
* une autre filme un marché ;
* une autre filme un monument ;
* une autre filme un quartier ;
* etc.

Les vidéos doivent pouvoir être transformées en véritables représentations spatiales 3D.

Les contributions seront géolocalisées et progressivement assemblées afin de constituer une représentation 3D de plus en plus vaste du territoire burkinabè.

L'architecture doit donc être pensée dès maintenant pour pouvoir évoluer vers :

BURKINA FASO
→ RÉGIONS
→ PROVINCES
→ VILLES
→ COMMUNES / DISTRICTS
→ QUARTIERS
→ RUES / LIEUX
→ SCÈNES 3D

Une même zone pourra également être capturée à différentes périodes afin de permettre ultérieurement une dimension temporelle.

# 4. PROBLÈME CENTRAL : LA VIDÉO UTILISATEUR

Ne pars pas du principe qu'une vidéo utilisateur sera parfaite.

Elle pourra être :

* filmée en marchant ;
* filmée depuis une voiture ;
* tremblante ;
* trop rapide ;
* mal éclairée ;
* avec des personnes ;
* avec des véhicules ;
* avec des zones peu texturées ;
* avec des objets mobiles ;
* avec des changements de lumière ;
* avec une mauvaise couverture spatiale.

Détermine quelles conditions minimales une vidéo doit respecter pour produire une reconstruction exploitable.

Propose un futur système de qualité permettant de déterminer automatiquement :

* vidéo acceptable ;
* vidéo exploitable avec avertissement ;
* vidéo insuffisante ;
* vidéo impossible à reconstruire.

Mais NE PAS encore implémenter ce système.

# 5. GÉORÉFÉRENCEMENT

C'est un point critique.

Une scène 3D ne doit pas être uniquement un objet visuel placé arbitrairement dans une page.

Elle doit pouvoir être associée à une position géographique réelle.

Étudier :

* coordonnées GPS ;
* système de coordonnées local ;
* système de coordonnées global ;
* orientation ;
* altitude ;
* transformation entre coordonnées locales et géographiques ;
* précision ;
* dérive GPS ;
* trajectoire GPS pendant la vidéo.

Déterminer comment une future scène pourrait être placée correctement sur la carte BurkinaWatch.

# 6. FUTURE CONNEXION ENTRE LES SCÈNES

C'est un point FONDAMENTAL du projet.

Nous ne voulons pas uniquement avoir :

comme des objets complètement indépendants.

À terme, nous voulons pouvoir obtenir :

SCÈNE A → SCÈNE B → SCÈNE C → SCÈNE D

pour progressivement reconstruire une rue, un quartier, puis une ville.

Étudier donc :

* alignement ;
* coordonnées ;
* orientation ;
* overlap entre captures ;
* points communs ;
* transformations spatiales ;
* détection de scènes voisines ;
* fusion ;
* recalage ;
* gestion des erreurs ;
* confiance dans les connexions.

Déterminer quelles technologies sont les plus adaptées à cette vision.
